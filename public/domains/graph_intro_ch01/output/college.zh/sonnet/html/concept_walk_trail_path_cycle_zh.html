Walk Trail Path Cycle

定义

在图论中，"游走"（walk）是顶点与边交替出现的序列 $v_0, e_1, v_1, e_2, v_2, \ldots, e_k, v_k$，其中每条边 $e_i$ 连接 $v_{i-1}$ 与 $v_i$；顶点和边都允许重复出现。游走的长度即所含边数 $k$。

在此基础上，三个概念依次施加更强的约束：

  • 迹（trail）：要求所有边互不相同（顶点可以重复）。
  • 路径（path）：要求所有顶点互不相同（因此边自然也互不相同，是比迹更强的约束）。
  • 圈（cycle）：一条闭合的迹（起点等于终点，$v_0 = v_k$），且除首尾顶点外，其余内部顶点互不相同，长度至少为 3（简单无向图中）。

    • 这四个概念构成一个包含关系：路径 $\subset$ 迹 $\subset$ 游走，而圈则是"闭合且内部无重复顶点"的特殊迹。

    实例演算

    考虑一个顶点集为 $\{A, B, C, D\}$ 的图，边集为 $\{AB, BC, CD, DA, AC\}$。

  • 序列 $A \to B \to C \to A \to D$ 是一条游走，但因为边 $AC$ 与 $CA$……实际上这里只用了一次 $AC$，顶点 $A$ 却重复出现，所以它是迹（若边未重复）但不是路径。
  • 序列 $A \to B \to C \to D$ 顶点全不相同，是一条路径。
  • 序列 $A \to B \to C \to D \to A$ 首尾顶点相同（$A$），内部顶点 $B, C, D$ 互不相同，边 $AB, BC, CD, DA$ 也互不相同，因此这是一个长度为 4 的圈。

    • 问题求解应用

    判别一个给定序列属于哪一类，本质上是一道约束检验题：先检查边是否重复（判定是否为迹），再检查顶点是否重复（判定是否为路径），最后检查首尾顶点是否相等且内部无重复（判定是否为圈）。这种分层检验方法在算法实现中非常直接——用一个集合记录已访问的边（或顶点），一旦发现序列中出现重复元素，就立刻可以排除更严格的分类。

    这一分类体系是许多经典图论算法的基础。例如，欧拉迹（Euler trail）要求恰好使用图中每条边一次，其存在性由"度为奇数的顶点数为 0 或 2"这一判据决定；哈密顿路径（Hamiltonian path）则要求经过每个顶点恰好一次，但目前没有已知的高效判定算法，是计算机科学中 NP 完全问题的经典例子。理解游走、迹、路径、圈之间的严格层级关系，是分析网络可达性、电路设计与最短路径算法（如 Dijkstra 算法要求所求为路径而非任意游走）的必要前提。
